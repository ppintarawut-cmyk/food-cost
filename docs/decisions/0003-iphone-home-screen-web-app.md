# ทำเป็นเว็บแอปที่ติดตั้งบนหน้าจอโฮมของ iPhone ไม่ใช่แอปในร้านค้าแอป

ผู้ใช้ใช้ iPhone คนเดียว จึงทำเป็นเว็บแอปที่ "เพิ่มไปยังหน้าจอโฮม" แทนแอปใน App Store
เพราะไม่ต้องเสียค่าสมัครนักพัฒนารายปี ไม่ต้องรอร้านค้าแอปตรวจ และอัปเดตได้ทันที

**ผลที่ตามมา**:
- Safari อาจลบข้อมูลของเว็บที่ไม่ได้เปิดนานประมาณ 7 วัน แต่เว็บแอปที่ติดตั้งบนหน้าจอโฮมไม่โดนกฎนี้
  จึงต้องให้ติดตั้งบนหน้าจอโฮมก่อนใช้งานจริง ห้ามใช้ผ่าน Safari ธรรมดา
- ข้อมูลยังหายได้ถ้ามือถือหายหรือลบแอปออก จึงต้องมีวิธีสำรองข้อมูล (ดู 0001)
