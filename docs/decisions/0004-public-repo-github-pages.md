# เก็บโค้ดใน repo สาธารณะ `food-cost` และเปิดเว็บด้วย GitHub Pages

โค้ดอยู่ใน repository ใหม่ `food-cost` แยกจากระบบเทรด และตั้งเป็นสาธารณะ เพื่อใช้ GitHub Pages แบบฟรีเปิดเว็บแอป
ปลอดภัยเพราะโค้ดไม่มีข้อมูลร้าน (อยู่ใน iPhone เท่านั้น ดู 0001) และไม่มีคีย์ AI (กรอกในมือถือ ดู 0002)

**ทางเลือกที่ไม่เลือก**:
- repo ส่วนตัว + บริการฟรีอื่น (Cloudflare Pages) — ต้องสมัครและเชื่อมบัญชีเพิ่ม
- ฝากใน VPS ของระบบเทรด — ผูกสองระบบไว้ด้วยกัน ถ้าเซิร์ฟเวอร์ล่ม แอปร้านเปิดไม่ได้

**ผลที่ตามมา**: ห้ามใส่ข้อมูลร้าน คีย์ หรือไฟล์สำรองจริงลงใน repo เด็ดขาด เพราะทุกคนอ่านได้
