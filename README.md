# ต้นทุนอาหาร (food-cost)

เว็บแอปบน iPhone สำหรับร้านอาหาร:

- จดราคาวัตถุดิบที่ซื้อมา (พิมพ์เอง หรือ **ถ่ายใบเสร็จให้ AI อ่าน**)
- ตั้งสูตรของแต่ละเมนู แล้วได้ **ต้นทุนต่อจาน** ทันที
- เห็น **กำไรต่อจาน** แยก หน้าร้าน / Grab / LINE MAN หลังหัก GP และ VAT ของค่า GP
- สรุปค่าซื้อวัตถุดิบรายวัน / รายเดือน

ข้อมูลทั้งหมดเก็บใน iPhone เครื่องเดียว ไม่มีเซิร์ฟเวอร์ (ดูเหตุผลใน `docs/decisions/`)

## ติดตั้งบน iPhone

1. เปิดลิงก์ของแอปใน **Safari**
2. กดปุ่ม **แชร์** (สี่เหลี่ยมมีลูกศรขึ้น) → **เพิ่มไปยังหน้าจอโฮม**
3. เปิดแอปจากไอคอนบนหน้าจอโฮมทุกครั้ง

> ต้องติดตั้งบนหน้าจอโฮมก่อนใช้งานจริง ถ้าเปิดผ่าน Safari ธรรมดาแล้วไม่ได้เปิดนาน iPhone อาจลบข้อมูลทิ้ง

## ใส่คีย์ AI (สำหรับถ่ายใบเสร็จ)

1. สร้างคีย์ที่ https://console.anthropic.com → API Keys
2. ตั้ง **วงเงินใช้จ่ายรายเดือน** ในหน้า Billing / Limits ไว้ด้วย
3. ในแอป ไปที่แท็บ **ตั้งค่า** → วางคีย์ → **บันทึกคีย์**

คีย์เก็บไว้ในเครื่องนั้นเท่านั้น และไม่ถูกใส่ในไฟล์สำรอง
ค่าอ่านใบเสร็จประมาณ 1–3 บาทต่อใบ (ใช้ Claude Opus 5.5 ราคา $4 / $20 ต่อล้านโทเคน)

## สำรองข้อมูล

แท็บ **ตั้งค่า** → **ส่งไฟล์สำรอง** → เลือก LINE แล้วส่งให้ตัวเอง
ถ้าเปลี่ยนเครื่อง: เปิดไฟล์จาก LINE → บันทึกลงแอปไฟล์ → ในแอปกด **กู้คืนจากไฟล์สำรอง**
แอปจะเตือนถ้าไม่ได้สำรองเกิน 7 วัน

## สำหรับคนพัฒนา

ไม่มีขั้นตอน build เป็นไฟล์ HTML / CSS / JavaScript ธรรมดา

```bash
npm test     # ทดสอบการคำนวณ (Node 22 ขึ้นไป)
npm start    # เปิดที่ http://localhost:8080
```

| ไฟล์ | หน้าที่ |
|---|---|
| `js/calc.js` | การคำนวณทั้งหมด (ต้นทุน GP กำไร สรุป) |
| `js/store.js` | เก็บข้อมูลในเครื่อง และไฟล์สำรอง |
| `js/receipt.js` | ส่งรูปให้ AI อ่าน และเตรียมหน้าจอตรวจ |
| `js/app.js` | หน้าจอทั้งหมด |
| `CONTEXT.md` | คำศัพท์ของโปรเจกต์ ใช้คำตามนี้เสมอ |
| `docs/decisions/` | บันทึกการตัดสินใจสำคัญ |

ทุกครั้งที่ push เข้า `main` GitHub Actions จะทดสอบแล้วอัปเดตเว็บบน GitHub Pages ให้เอง
