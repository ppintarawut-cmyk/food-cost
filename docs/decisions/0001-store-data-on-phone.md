# เก็บข้อมูลไว้ในมือถือเครื่องเดียว ไม่มีเซิร์ฟเวอร์เก็บข้อมูล

โปรแกรมทำให้ผู้ใช้คนเดียว (แฟนของผู้สร้าง) ใช้บนมือถือเครื่องเดียว จึงเก็บวัตถุดิบ เมนู และประวัติการซื้อทั้งหมดไว้ในเครื่อง
ไม่มีระบบล็อกอินหรือฐานข้อมูลออนไลน์ เพราะใช้คนเดียว ไม่ต้องดูแลเซิร์ฟเวอร์ และไม่มีค่าใช้จ่ายรายเดือน

**ทางเลือกที่ไม่เลือก**: เก็บออนไลน์พร้อมล็อกอิน (เปิดได้หลายเครื่อง ข้อมูลไม่หายถ้ามือถือหาย แต่ต้องมีเซิร์ฟเวอร์และดูแลต่อเนื่อง)

**ผลที่ตามมา**: ถ้ามือถือหาย/พัง หรือล้างข้อมูลเบราว์เซอร์ ประวัติจะหาย ต้องมีวิธีสำรองข้อมูล
ถ้าวันหนึ่งต้องการให้คนที่สองใช้ด้วย จะต้องย้ายข้อมูลไปเก็บออนไลน์ ซึ่งเป็นงานใหญ่
